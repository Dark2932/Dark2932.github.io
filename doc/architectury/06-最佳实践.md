# 最佳实践

本文档总结了使用 Architectury 进行 Minecraft 1.21.1 模组开发的最佳实践。

## 项目结构


## 代码组织原则

### 1. 单一职责原则 - "一个类只做一件事"

```
❌ 错误：一个巨大的 ModContent 类，里面啥都有
✅ 正确：ModItems 只管物品，ModBlocks 只管方块
```

```java
// ❌ 错误：一个类做太多事情
public class ModContent {
    public static final DeferredRegister<Item> ITEMS = ...;
    public static final DeferredRegister<Block> BLOCKS = ...;
    public static final DeferredRegister<EntityType<?>> ENTITIES = ...;
}

// ✅ 正确：分离关注点
public class ModItems {
    public static final DeferredRegister<Item> ITEMS = ...;
    public static void register() { ITEMS.register(); }
}

public class ModBlocks {
    public static final DeferredRegister<Block> BLOCKS = ...;
    public static void register() { BLOCKS.register(); }
}
```

**通俗理解**：就像公司的不同部门，人事部只管人事，财务部只管财务，不要混在一起。

### 2. 常量类 - "把 ID 集中管理"

```java
public final class ModConstants {
    public static final String MOD_ID = "yourmod";
    
    private ModConstants() {}  // 防止被实例化
}

// 使用
public static final DeferredRegister<Item> ITEMS = 
    DeferredRegister.create(ModConstants.MOD_ID, Registries.ITEM);
```

**为什么？** 如果你有 100 个地方用到 `MOD_ID`，改起来只需要改一处。

### 3. 延迟初始化 - "别急着创建对象"

```java
// ❌ 错误：直接创建 Item（可能在游戏还没准备好时就创建了）
public static final Item EXAMPLE = new Item(new Item.Properties());

// ✅ 正确：用延迟注册（等游戏准备好再创建）
public static final RegistrySupplier<Item> EXAMPLE = 
    ITEMS.register("example", () -> new Item(new Item.Properties()));
```

**通俗理解**：不要在餐厅还没开门时就摆盘子（❌），等客人来了再上菜（✅）。

## 注册最佳实践

### 1. 集中注册 - "所有注册代码放在一起"

```java
public class ModItems {
    public static final DeferredRegister<Item> ITEMS = 
        DeferredRegister.create(MOD_ID, Registries.ITEM);
    
    // 物品
    public static final RegistrySupplier<Item> RUBY = 
        ITEMS.register("ruby", () -> new Item(props()));
    
    // 方块物品
    public static final RegistrySupplier<BlockItem> RUBY_BLOCK_ITEM = 
        ITEMS.register("ruby_block", 
            () -> new BlockItem(ModBlocks.RUBY_BLOCK.get(), props()));
    
    // 生成蛋
    public static final RegistrySupplier<Item> RUBY_GOLEM_EGG = 
        ITEMS.register("ruby_golem_egg", 
            () -> new ArchitecturySpawnEggItem(
                ModEntities.RUBY_GOLEM, 0xFF0000, 0x00FF00, props()));
    
    // 通用物品属性
    private static Item.Properties props() {
        return new Item.Properties().arch$tab(ModTabs.GEMS_TAB);
    }
    
    public static void register() {
        ITEMS.register();
    }
}
```

### 2. 注册顺序 - "先标签，再物品，最后实体"

```java
public class YourMod {
    public static void init() {
        ModTabs.register();      // 1. 先注册标签（因为物品要放到标签里）
        ModItems.register();     // 2. 再注册物品
        ModBlocks.register();    // 3. 注册方块
        ModEntities.register();  // 4. 最后注册实体
        ModEvents.register();    // 5. 注册事件
        ModNetwork.register();   // 6. 注册网络
    }
}
```

**为什么？** 如果标签还没注册，物品就找不到放哪个标签页。

## 事件处理

### 1. 集中管理事件

```java
public class ModEvents {
    public static void register() {
        // 实体事件
        EntityEvent.LIVING_HURT.register(ModEvents::onLivingHurt);
        
        // 方块事件
        BlockEvent.PLACE.register(ModEvents::onBlockPlace);
        
        // 玩家事件
        PlayerEvent.PLAYER_JOIN.register(ModEvents::onPlayerJoin);
    }
    
    private static EventResult onLivingHurt(LivingEntity entity, DamageSource source, float amount) {
        // 处理逻辑
        return EventResult.pass();
    }
}
```

### 2. 永远返回 EventResult

```java
// ❌ 错误：忘记返回值
EntityEvent.LIVING_HURT.register((entity, source, amount) -> {
    handleHurt(entity);
    // 忘记返回！
});

// ✅ 正确：总是返回值
EntityEvent.LIVING_HURT.register((entity, source, amount) -> {
    handleHurt(entity);
    return EventResult.pass();
});
```

### 3. 避免内存泄漏

```java
// ❌ 错误：把实体存起来（它不会被垃圾回收）
EntityEvent.LIVING_HURT.register((entity, source, amount) -> {
    someList.add(entity);  // 永远不会释放！内存会爆！
    return EventResult.pass();
});

// ✅ 正确：只在需要时处理，不长期持有引用
EntityEvent.LIVING_HURT.register((entity, source, amount) -> {
    if (entity instanceof Player) {
        handlePlayerHurt((Player) entity);
    }
    return EventResult.pass();
});
```

## 网络通信

### 1. 验证所有数据

```java
NetworkManager.registerReceiver(Side.C2S, PACKET_ID, (buf, context) -> {
    // 1. 检查大小
    if (buf.readableBytes() > 1024) return;
    
    // 2. 检查权限
    if (!context.getPlayer().hasPermissions(2)) return;
    
    // 3. 验证数据
    try {
        BlockPos pos = buf.readBlockPos();
        if (!isValidPosition(pos)) return;
    } catch (Exception e) {
        return;  // 解析失败，丢弃
    }
    
    // 4. 主线程执行
    context.queue(() -> {
        // 安全修改
    });
});
```

### 2. 使用结构化消息类

```java
// 定义消息格式
public class TeleportMessage {
    private final BlockPos pos;
    
    public TeleportMessage(FriendlyPacketBuf buf) {
        this.pos = buf.readBlockPos();
    }
    
    public TeleportMessage(BlockPos pos) {
        this.pos = pos;
    }
    
    public void encode(FriendlyPacketBuf buf) {
        buf.writeBlockPos(pos);
    }
    
    public void apply(Supplier<PacketContext> context) {
        context.get().queue(() -> {
            // 处理
        });
    }
}
```

## 常见陷阱

### 1. 静态初始化顺序

```java
// ❌ 可能出错：items 依赖 tab，但 tab 还没注册
public static final RegistrySupplier<CreativeModeTab> TAB = ...;
public static final RegistrySupplier<Item> ITEM = 
    ITEMS.register("item", () -> new Item(new Item.Properties().arch$tab(TAB)));

// ✅ 安全：用方法引用延迟求值
public static final RegistrySupplier<Item> ITEM = 
    ITEMS.register("item", () -> new Item(new Item.Properties().arch$tab(ModTabs.TAB)));
```

### 2. 平台特定导入

```java
// ❌ 在 common 中导入 Fabric 类
import net.fabricmc.loader.api.FabricLoader;  // 编译错误！

// ✅ 用 @ExpectPlatform
@ExpectPlatform
public static boolean isModLoaded(String modId) {
    throw new AssertionError();
}
```

### 3. 线程安全

```java
// ❌ 在错误的线程修改世界
NetworkManager.registerReceiver(Side.C2S, ID, (buf, ctx) -> {
    level.setBlockAndUpdate(pos, state);  // 可能崩溃！
});

// ✅ 用 queue() 切换到主线程
NetworkManager.registerReceiver(Side.C2S, ID, (buf, ctx) -> {
    ctx.queue(() -> level.setBlockAndUpdate(pos, state));
});
```

## 总结

| 原则 | 说明 |
|------|------|
| **单一职责** | 每个类只做一件事 |
| **集中管理** | 注册代码、事件代码分别放在一起 |
| **延迟初始化** | 用 RegistrySupplier，不要直接创建对象 |
| **验证数据** | 永远不信任客户端发来的数据 |
| **线程安全** | 网络回调用 context.queue() |
| **返回值** | 事件处理器永远返回 EventResult |
