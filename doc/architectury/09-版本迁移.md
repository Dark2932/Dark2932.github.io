# 版本迁移指南

本文档提供 Architectury 版本迁移的指导，适用于 Minecraft 1.21.1 版本。

> 💡 **什么时候需要看这个文档？** 当你把模组从旧版本 Minecraft 升级到新版本时，或者从 Forge 迁移到 NeoForge 时。

## 迁移到 Architectury 14 (1.21.1)

### 主要变化

1. **Java 版本**：要求 Java 17
2. **Gradle 版本**：要求 Gradle 8.1+
3. **NeoForge 支持**：正式支持 NeoForge
4. **注册系统**：优化了注册 API
5. **事件系统**：改进了事件处理

### 更新步骤

#### 1. 更新 gradle.properties

```properties
# 旧版本
architectury_version=12.0.0
minecraft_version=1.20.4
fabric_version=0.97.0
forge_version=49.0.1

# 新版本
architectury_version=14.0.3
minecraft_version=1.21.1
fabric_version=0.16.0
fabric_loader_version=0.16.9
forge_version=52.0.16
neoforge_version=21.1.77
```

#### 2. 更新 build.gradle

```groovy
plugins {
    // 更新版本
    id "architectury-plugin" version "3.4-SNAPSHOT"
    id "dev.architectury.loom" version "1.7-SNAPSHOT" apply false
}

architectury {
    minecraft = rootProject.minecraft_version
}
```

#### 3. 更新 NeoForge 配置

```groovy
// neoforge/build.gradle
dependencies {
    minecraft "com.mojang:minecraft:${rootProject.minecraft_version}"
    mappings loom.officialMojangMappings()
    
    // 更新 NeoForge 版本
    neoForge "net.neoforged:neoforge:${rootProject.neoforge_version}"
    
    modImplementation "dev.architectury:architectury:${rootProject.architectury_version}"
}

architectury {
    platformSetupLoomIde()
    neoforge()
}
```

### API 变化

#### 注册 API

```java
// 旧版本
public static final Supplier<Registries> REGISTRIES = 
    Suppliers.memoize(() -> Registries.get(MOD_ID));

Registrar<Item> items = REGISTRIES.get().get(Registry.ITEM_KEY);

// 新版本
public static final Supplier<RegistrarManager> MANAGER = 
    Suppliers.memoize(() -> RegistrarManager.get(MOD_ID));

Registrar<Item> items = MANAGER.get().get(Registries.ITEM);
```

#### 创意标签

```java
// 旧版本
public static final CreativeTabRegistry.TabSupplier MY_TAB = 
    CreativeTabRegistry.create(
        new ResourceLocation("modid", "test_tab"),
        () -> new ItemStack(Items.STONE));

// 新版本
public static final DeferredRegister<CreativeModeTab> TABS = 
    DeferredRegister.create("modid", Registries.CREATIVE_MODE_TAB);

public static final RegistrySupplier<CreativeModeTab> MY_TAB = 
    TABS.register("test_tab", 
        () -> CreativeTabRegistry.create(
            Component.translatable("category.modid"),
            () -> new ItemStack(Items.STONE)));
```

#### 物品属性

```java
// 旧版本
new Item.Properties().tab(MY_TAB);

// 新版本
new Item.Properties().arch$tab(MY_TAB);
```

## 迁移到 NeoForge

### 从 Forge 迁移到 NeoForge

#### 1. 更新配置

```properties
# 移除 Forge
# forge_version=52.0.16

# 添加 NeoForge
neoforge_version=21.1.77
```

#### 2. 更新 build.gradle

```groovy
// 旧版本 (Forge)
dependencies {
    forge "net.minecraftforge:forge:${rootProject.forge_version}"
}

architectury {
    forge()
}

// 新版本 (NeoForge)
dependencies {
    neoForge "net.neoforged:neoforge:${rootProject.neoforge_version}"
}

architectury {
    neoforge()
}
```

#### 3. 更新模组入口

```java
// 旧版本 (Forge)
@Mod(YourMod.MOD_ID)
public class YourModForge {
    public YourModForge() {
        EventBuses.registerModEventBus(YourMod.MOD_ID, 
            FMLJavaModLoadingContext.get().getModEventBus());
        YourMod.init();
    }
}

// 新版本 (NeoForge)
@Mod(YourMod.MOD_ID)
public class YourModNeoForge {
    public YourModNeoForge(IEventBus eventBus) {
        EventBuses.registerModEventBus(YourMod.MOD_ID, eventBus);
        YourMod.init();
    }
}
```

#### 4. 更新 mods.toml → neoforge.mods.toml

```toml
# 旧版本 (mods.toml)
modLoader = "javafml"
loaderVersion = "[49,)"

# 新版本 (neoforge.mods.toml)
modLoader = "javafml"
loaderVersion = "[4,)"
```

#### 5. 更新平台特定代码

```java
// 旧版本 (Forge)
import net.minecraftforge.fml.ModList;
import net.minecraftforge.fml.loading.FMLPaths;

// 新版本 (NeoForge)
import net.neoforged.fml.ModList;
import net.neoforged.fml.loading.FMLPaths;
```

### 保持 Forge 和 NeoForge 兼容

可以同时支持 Forge 和 NeoForge：

```groovy
// settings.gradle
include('common', 'fabric', 'forge', 'neoforge')

// build.gradle
subprojects {
    architectury {
        // 根据模块名称判断平台
        if (project.name == 'fabric') {
            platformSetupLoomIde()
            fabric()
        } else if (project.name == 'forge') {
            platformSetupLoomIde()
            forge()
        } else if (project.name == 'neoforge') {
            platformSetupLoomIde()
            neoforge()
        }
    }
}
```

## 常见迁移问题

### 1. 类找不到错误

**问题**：`NoClassDefFoundError`

**原因**：使用了平台特定 API

**解决**：使用 Architectury API 或 @ExpectPlatform

### 2. Mixin 失败

**问题**：`MixinApplyError`

**原因**：Mixin 目标方法签名变化

**解决**：更新 Mixin 目标方法签名

### 3. 注册顺序问题

**问题**：内容未正确注册

**原因**：注册时机不正确

**解决**：确保在正确的时机调用 register()

### 4. 映射不匹配

**问题**：方法/字段找不到

**原因**：模块使用了不同的映射

**解决**：确保所有模块使用相同的映射配置

### 5. 依赖版本冲突

**问题**：依赖解析失败

**原因**：依赖版本不兼容

**解决**：更新依赖版本，使用版本范围

```groovy
dependencies {
    // 使用版本范围
    implementation 'com.example:lib:[1.0,2.0)'
}
```

## 回滚

如果迁移失败，可以：

1. 使用 Git 回滚到之前的版本
2. 恢复 gradle.properties 中的版本号
3. 恢复 build.gradle 配置
4. 重新构建和测试
